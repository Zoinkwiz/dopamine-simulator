# Dopamine Simulator

A RuneLite plugin that adds a self-contained collection game on top of Old School RuneScape,
as a parody of the progression systems found in free-to-play mobile games.

**There is no real money in this plugin.** Nothing can be purchased, there are no
microtransactions, no external services and no network calls. The only currency is Points,
which you earn by playing Old School RuneScape normally. Everything is stored in a local save
file and affects nothing outside the plugin panel.

Everything you do earns Points. Points buy upgrades and card packs. Packs contain cards, and the
cards you collect get you more points.

## Getting Points

Start off clicking the gold button to get points. As you get points, you'll unlock new ways to get points, and ways to enhance the amount of points point-sources give.

## Card Packs

Points can also be spent on card packs. Cards come in rarities, with shiny and gilded variants
and a star system for duplicates, so there is plenty to fill in.

<img width="910" height="796" alt="image" src="https://github.com/user-attachments/assets/acd714a8-9d39-4164-9f3f-2cc03a6b3e72" />

## Cards from elsewhere

Not every card is in the packs. The raid megarares only ever come off a banner, the region cards
only from finishing a season pass, the skill mastery cards only from prestiging, and the
character cards only from doing the content that character belongs to.

## Season Pass

A season pass, because of course there is one. Earn experience to move along the track and
collect packs and rewards as you go. A second track can be opened with Points you have already
earned; it costs nothing but Points, and no track expires in a way that can be paid to avoid.

## Banner

The banner is where the megarare cards live. Pulls are random, and a guaranteed result arrives
after a set number of pulls so a run of bad luck cannot go on forever. Pulls are paid for with
Points earned in game.
